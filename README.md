## About This Repository

This repository is a full, consulting-grade Product Management case study for **Jentara**, a premium Gen-Z streetwear and sustainable fashion D2C brand. It is structured the way a PM/strategy deliverable would be structured inside a top product organization or consulting engagement (McKinsey / Deloitte / Accenture-style structuring, Amazon/Google-style PRDs, Shopify/Myntra-style commerce specifics).

Because a document of this scope (16 sections, 100+ sub-deliverables) is genuinely large, it is being built **incrementally, section by section, at full depth** rather than compressed into shallow bullet points. This keeps every section usable on its own — a PRD a engineer could actually build from, a market analysis an investor could actually diligence against.
